# SermonROAD

개혁주의 설교자를 위한 설교 기록 · 준비 앱 — 어떤 본문으로, 어떤 제목과 내용으로, 어디에서 설교했는지 66권 위에 기록하고 준비해요.

- 설교 지도 (66권) · 설교 달력 (스케줄러) · 설교 기록 (기간 › 연도 › 월)
- 강해 시리즈 · 요리문답 · 신앙고백 추적 · 예화 보관함 · 같은 본문 · 같은 장소 알림
- 설교 도우미: 내 서재 PDF 를 근거로 AI(Claude · ChatGPT · 제미나이 중 선택)가 정리 · 구조 · 묵상 · 설교 개요 · 개혁주의 관점 (API 키 또는 구독 복사 방식, 다른 AI 로도 받아 비교)
- 자동 백업 · 엑셀 내보내기 · 자동 업데이트 · 라이트/다크
